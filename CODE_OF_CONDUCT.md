# Code of Conduct

## Our standards

We expect everyone participating in this project to:

- be respectful and constructive
- focus on the code, design, and documentation
- avoid harassment, discrimination, and abusive behavior
- keep feedback specific, actionable, and calm
- respect maintainers, contributors, and users

## Unacceptable behavior

The following are not acceptable in this project:

- personal attacks or insults
- harassment, threats, or intimidation
- discriminatory language or exclusionary conduct
- repeated disruptive behavior
- attempts to shame, dox, or target contributors

## Enforcement

Project maintainers may remove, hide, or lock content, reject contributions, or restrict participation when behavior harms the project or its community.

## Reporting

If you need to report harmful behavior, use a private GitHub issue or another private maintainer contact path already established for the project.

## Scope

This code of conduct applies to issues, pull requests, discussions, comments, and any project communication channels maintained for Oxid.
