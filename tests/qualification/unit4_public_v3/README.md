acceptance and successful qualification are separate: an expected rejection can
qualify. Every declared host has a tuple. Required other hosts are unavailable and
unqualified; excluded hosts have one explicit frozen-scope exclusion receipt.
Current successful execution qualifies only the current host. It cannot create a
global pass. An unavailable permission capability is an explicit unqualified gap.

Original streams retain all124 complete envelopes in both profiles. Predecessors
retain3603 Unit2 plus152 Unit3 cases; partial first-diagnostic, frontend-prefix and
schema/source projections remain partial. No public result claims private raw,
event, fuel or archived predecessor qualification. Lifecycle counters are logical
stage entries/completions, never OS syscall counts. Direct source coordinates are
validated even when a contract deliberately limits semantic diagnostic comparison.

Compiler binding records distinguish the actual Git head/full tree from the
source-only patch tree; the exact current-source manifest and profile build
receipts are the executable authority. Correcting a provenance label does not
change existing build receipts or binaries.
