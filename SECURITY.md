# Security Policy

## Supported versions

Security fixes are provided on the current main branch and the latest release line.

## Reporting a vulnerability

Please report security issues through GitHub Security Advisories for this repository. If that is not available, open a private security report instead of a public issue whenever possible.

Send a private report that includes:

- a short summary of the issue
- affected files or modules
- reproduction steps
- expected impact
- any relevant logs, screenshots, or proof-of-concept details

## Safe handling

Please keep reports focused on defensive verification and coordinated disclosure. Avoid sharing exploit details publicly until a fix is available.

## Scope

This policy covers the Oxid runtime, Oxid source files under `stdlib/`, `examples/`, `tools/`, `docs/`, and the native bootstrap code under `src/`.
