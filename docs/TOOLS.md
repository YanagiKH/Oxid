# Tooling

Oxid ships with:

- `run`
- `script`
- `repl`
- `check`
- `watch`
- `build`
- `clean`
- `fmt`
- `test`
- `doctor`
- `doc`
- `new`
- `init`
- `add`

These commands are intended to cover the full everyday workflow without external tools.
The runtime also keeps a local preprocess cache under `.oxid/cache` for faster repeat runs.
